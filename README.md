# Warner Bros Movie Website - School Assignment

This project is a **recreation of the iconic Warner Bros movie website**, built as part of a school assignment to demonstrate proficiency in **HTML, CSS, JavaScript, and Bootstrap**.

## 🎬 Project Overview

The goal of this assignment was to replicate the look and feel of the official Warner Bros website using front-end web development technologies. The website features a modern, responsive design and includes pages or sections for:

- Featured movies
- Trailers and media content
- Movie details and cast
- Navigation and interactive elements
- Footer with social links and contact info

> ⚠️ **Disclaimer:** This project is for educational purposes only. All rights to Warner Bros content and branding belong to Warner Bros. Entertainment Inc.

To view the website locally:

2. Open `index.html` in your browser.
3. Make sure all related assets (CSS, JS, images) are in the correct folders.
